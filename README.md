# 户外品牌达人投放分析案例

围绕下一轮投放的达人筛选、内容方向与预算配置，提供案例报告、交互分析看板及经营复盘。

## 在线查看

- [案例报告](https://oi-ctfsky.github.io/outdoor-seeding-analysis/)
- [达人与内容看板](https://oi-ctfsky.github.io/outdoor-seeding-analysis/strategy.html)
- [经营复盘看板](https://oi-ctfsky.github.io/outdoor-seeding-analysis/dashboard.html)

## 分析范围

内容模块包含 180 条视频、149 位匿名达人，以每条视频 21 天观察窗口比较表现。交易模块为独立的模拟订单数据，不与内容模块混算。

案例基于学习资料与模拟交易数据。品牌、账号、达人及视频身份已匿名化。筛选阈值和策略为分析原型，未声称后续投放已获得业绩提升；成本估算、缺失报价、转化去重及 ROI 的适用边界见网页口径附录。

## 使用

本项目为静态网页，无需构建；打开 index.html 即可查看，也可通过 GitHub Pages 发布。页面支持达人与商品下钻、候选阈值调整及内容表现比较。
